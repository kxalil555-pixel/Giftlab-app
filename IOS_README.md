# GiftLab iOS — imzosiz IPA (GitHub Actions)

1. Repo yarating, shu papkani push qiling (modellar `miniapp/models/` ichida bo'lsin).
2. Actions → "iOS IPA (unsigned, ESign uchun)" → Run workflow (push qilganda o'zi ham ishlaydi).
3. Tugagach Artifacts → `GiftLab-ipa` → GiftLab.ipa ni yuklab, ESign bilan o'z sertifikatingizda imzolang.

Eslatma: `ios/App/config.json` da `apiBase` bo'sh bo'lsa ilova offline DEMO rejimida ishlaydi.
